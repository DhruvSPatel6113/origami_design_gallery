# Origami Design Gallery

> Responsive web application showcasing step-by-step origami folding designs and diagrams

## Overview
A responsive educational web application celebrating the art of origami paper folding. Provides interactive galleries, step-by-step folding guides, and visual diagrams for paper crafters of all skill levels.

## Features
- **Curated Design Catalog**: Categorized guides for traditional models (cranes, birds, animals, geometric shapes).
- **Responsive Card Grid**: Fluid layout adapting smoothly across mobile, tablet, and desktop screens.
- **Visual Step-by-Step Instructions**: Clear illustrated steps detailing valley folds, mountain folds, and base folds.

## Tech Stack
- **HTML5** & **Semantic Markup**
- **CSS3** (Flexbox, CSS Grid, media queries, smooth animations)

## Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/DhruvSPatel6113/origami_design_gallery.git
   cd origami_design_gallery
   ```
2. Open `index.html` directly in your browser.
